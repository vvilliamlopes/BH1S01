# BH1S01 — BLACK HOLE III — ONE — Sequence 01

This repository contains a Vite + Three.js implementation of Sequence 01 ("The Room").

Run locally:

1. npm install
2. npm run dev

Build:

1. npm run build
2. npm run preview

Deploy:

Connect the repository to Netlify and set the branch to BH01S01. Build command: `npm run build`. Publish directory: `dist`.

Notes:
- This initial implementation uses procedural textures to avoid large assets. Adjust particle counts and renderer DPR in src/scene.js for mobile performance.
